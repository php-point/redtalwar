# 🟥 Red Talwar - VS Code Theme ⚔️

**Red Talwar** is a modern, sharp, and energetic VS Code color theme  
inspired by strength, focus, and bold creativity.  
Perfect for developers who love deep contrast and a blazing red accent 🔥  

---

## ✨ Features
- ⚔️ Striking red tones with dark background for minimal eye strain  
- 💻 Clean syntax highlighting for PHP, JavaScript, HTML, CSS, and more  
- 🌙 Looks stunning in both dark and dimly-lit environments  
- 🧠 Balanced colors for long coding sessions
